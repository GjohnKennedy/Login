# Login

An Android sign-in and registration flow in Kotlin, talking to a REST backend with **Retrofit**.

- Login and registration screens with input validation
- A form screen, and a post-login area with a navigation drawer and fragments (home, notifications, settings)
- Retrofit + Gson for the API calls, Kotlin Coroutines for the requests
- Navigation component for moving between the fragments

**Stack:** Kotlin · Retrofit · Gson · Coroutines · Navigation component · Material Components · XML layouts

## Getting started

Clone, open in Android Studio and point `MyApi` at your own backend before running.

## Status

An early practice project from learning REST integration and the navigation component. Kept as a record of that work.
